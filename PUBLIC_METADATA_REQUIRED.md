# Public repository metadata pending

ProjectReader Core's author and license metadata are complete for `0.1.0a1`.
The following optional URLs remain intentionally absent from package metadata
until the public GitHub repository is created:

- project homepage URL
- public source repository URL
- public issue tracker URL

Do not invent these values. After repository creation, add only the real URLs
under `[project.urls]`, rebuild the distributions, and repeat the metadata and
archive checks before publication.

No private email address is required or published. Security reports should use
GitHub Private Vulnerability Reporting after it is enabled for the repository;
see [SECURITY.md](SECURITY.md).
